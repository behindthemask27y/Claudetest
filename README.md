# Skills de ciberseguridad (rama separada)

818 skills de ciberseguridad para Claude Code, de
[mukul975/Anthropic-Cybersecurity-Skills](https://github.com/mukul975/Anthropic-Cybersecurity-Skills).

Están en una **rama aparte** del repo del proyecto a propósito: así no se cargan
en cada mensaje cuando Cris trabaja en marketing, ads o Dueño vende (eso gastaba
créditos de más).

## Cómo usarlas
Abrí una sesión de Claude Code **sobre esta rama** (`ciberseguridad-skills`). Ahí
las 818 quedan en `.claude/skills/` y se cargan solas. En la rama del proyecto
(`claude/meta-ads-prospecting-9jlnxv`) no están.

Instaladas el 10-oct-2026. Copiadas sin correr instaladores remotos.
